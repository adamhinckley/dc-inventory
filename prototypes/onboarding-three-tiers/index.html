Prototype

Onboarding Three Tiers

Buyer apply → staff review (or staff-create) → org / staff invites → set password from the invite link. Open any screen; nothing persists past a refresh.

1. Wholesale Apply

Buyer self-serve on the shop. Resale license + issuing state required. No login yet.

2. Internal Review Queue

Pending applications (not Customers). Approve, reject, or create a customer for them.

3. Create Organization

DEFAULT / platform admin only. Org slug + first admin email. Invite, no password.

4. Create Staff

Admin invites staff. Multi-select G8 roles. At least one role required.

5. Set Password

Invite link. Rules shown before submit. Client-side validation. Then “You can log in.”
