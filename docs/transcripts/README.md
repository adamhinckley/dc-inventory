# Transcripts

Customer and discovery calls, cleaned for the repo.

## Layout

Each call lives in a folder named with the call date (`YYYY-MM-DD`):

```
docs/transcripts/YYYY-MM-DD/
  transcript.md
  highlights.md
```

If two calls land on the same day, keep them in that date folder and name the files so they do not collide (`transcript-david-smith.md`, `highlights-david-smith.md`).

## What to put in each file

**`transcript.md`.** Speaker-attributed markdown. Fix names, timestamps, and ASR mistakes. Cut filler and false starts. Keep the actual conversation, not a rewrite of what they "meant."

**`highlights.md`.** Separate from the transcript. What mattered: product requirements, current software, money, seasons, open questions. Write it so someone who did not join the call can act on it.

Drop Otter (or other vendor) watermarks. Do not invent quotes.
